# EMBED Engine Roadmap

**Version:** 1.0

**Status:** Living Document

---

# Purpose

This document defines the long-term evolution of EMBED Engine.

It is not a sprint backlog.

It is not a task list.

It defines the product development roadmap from the current MVP to the first successful commercial deployment.

---

# Vision

EMBED Engine is a modular sales platform that transforms static presentations into guided interactive customer journeys.

Every application shares:

- one architecture
- one geometry system
- one design language
- one AI layer
- one data layer

Applications differ only in their purpose.

# Long-term Vision

EMBED Engine is not a real estate application.

Real estate is only the first validation domain.

The long-term objective is to build a reusable platform for guided interactive product presentations and digital sales experiences across multiple industries.

---

# Guiding Principle

We are not building individual applications.

We are building one reusable system from which applications emerge.
