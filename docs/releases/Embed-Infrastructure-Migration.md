# Embed Infrastructure Migration

**Ticket:** PT-EMBED-MIGRATION-01  
**Date:** 2026-07-29  
**Status:** Repo + documentation complete — partner CMS cutover required for production PASS

## Cause

Production partner hosts (notably BaseKit on `https://www.domysenergii.cz/embed`) still ran the historical official snippet:

```html
script src="https://radimventus.github.io/embed-engine/embed/embed.iife.js?v=embed-01"
assetBase: "https://radimventus.github.io/embed-engine"
```

That `assetBase` was generated by `packages/embed/scripts/sync-pages.mjs` when the public origin was still the `github.io` project URL. After the custom domain `conis.cz` was attached, GitHub Pages began **301-redirecting** `radimventus.github.io/embed-engine/*` → `https://conis.cz/*`. Browser `fetch()` of house-package CSV across that redirect fails CORS → `Builder House Package bootstrap failed: Failed to fetch`.

Runtime and Builder were correct: they only prefix `/house-package/*` with the host-supplied `assetBase`.

## Fixed

| Area | Change |
| --- | --- |
| Publish scripts | `PAGES_ORIGIN = "https://conis.cz"` in `sync-pages.mjs`, `publish-release.mjs`, `validate-pages.mjs` |
| Official snippet | `docs/embed/OFFICIAL-PARTNER-SNIPPET.html` — script + `assetBase` on `conis.cz` only (`?v=embed-01`) |
| QA hosts | `live.html`, `partner-snippet.html`, `index.html` |
| Distribution docs | [GitHub Pages Distribution.md](./GitHub%20Pages%20Distribution.md) rewritten for conis.cz |
| AI Delivery CORS | Default allowlist uses `https://conis.cz` / `https://www.conis.cz` |
| Ops | [Migration checklist](../ops/embed-migration-checklist.md), [simplified snippet proposal](../ops/embed-simplified-partner-snippet-proposal.md) |

## How to validate

1. Repo gate: no production load URL under `apps/`, `packages/embed/scripts/`, `docs/embed/`, or AI edge **defaults** pointing at `radimventus.github.io`.
2. Live assets: `https://conis.cz/embed/embed.iife.js` and `https://conis.cz/house-package/gallery.csv` return 200.
3. Partner CMS updated per checklist (DSE widget must be re-pasted).
4. On partner page DevTools → Network: only `https://conis.cz/house-package/*`; **no** `radimventus.github.io`.

## Impact

| Surface | Impact |
| --- | --- |
| Existing partners with old snippet | **Broken until CMS update** (CORS on CSV) |
| New partners | Must use official conis.cz snippet only |
| `radimventus.github.io` bookmarks | Still 301 to conis.cz for document loads; must not be used as `assetBase` |
| Runtime / Builder code | No behavior change beyond consuming corrected `assetBase` |
| Historical `docs/reviews/**` | Archival URLs may still mention github.io — not production install instructions |

## Partner action (required)

Replace the BaseKit embed widget with the contents of `docs/embed/OFFICIAL-PARTNER-SNIPPET.html`. See [Migration Checklist §4](../ops/embed-migration-checklist.md).
