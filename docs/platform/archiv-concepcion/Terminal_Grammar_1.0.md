# Terminal Grammar 1.0

## Purpose

Terminal Grammar defines the common composition model shared by every
Embed Engine terminal.

A terminal is not an application. A terminal is a Runtime projection
optimized for a Perspective.

## Universal Structure

Context ↓ Narrative ↓ Insight ↓ Action

### Context

Where am I? What object, identity or scope am I working with?

### Narrative

What is happening? What is the current story or timeline?

### Insight

What does it mean? What patterns or recommendations emerge?

### Action

What should happen next?

## Examples

### Client Terminal

Context: My situation Narrative: Decision Story Insight: Why this
matters Action: Continue decision

### Operations Terminal

Context: Live activity Narrative: Timeline Insight: AI insights & trends
Action: Investigate / Assign / Contact

### Sales Terminal

Context: Decision Identity Narrative: Decision Journey Insight: Signals
& AI recommendations Action: Next Best Action

### Builder Terminal

Context: Knowledge model Narrative: Model evolution Insight: Impact
analysis Action: Improve model

## Principle

All terminals share the same grammar. Only Context and Narrative differ.
Insight and Action remain consistent Runtime projections.
