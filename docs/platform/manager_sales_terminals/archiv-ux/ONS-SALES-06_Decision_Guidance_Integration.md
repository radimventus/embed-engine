# ONS-SALES-06

## Účel
Rozšířit Sales Studio o inteligentní podporu obchodníka.

## Změny

### Dashboard
- KPI lišta
- AI Doporučení
- Poslední aktivita

### Detail případu
- Decision Journey
- Next Best Action
- AI Guidance

## UX
- Apple Easy
- One Screen → One Question
- AI doporučuje, obchodník rozhoduje.

## Akceptace
Obchodník po otevření případu okamžitě vidí:
1. kde se klient nachází,
2. co se stalo naposledy,
3. jaký je doporučený další krok.
