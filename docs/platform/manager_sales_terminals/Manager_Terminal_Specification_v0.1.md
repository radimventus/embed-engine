# Manager Terminal Specification v0.1

## Účel

Manager Terminal je hlavní pracovní prostředí vedoucího. Neposkytuje
pouze přehled, ale vede manažera k činnostem s nejvyšším dopadem.

## Hlavní otázka

**Co právě teď vyžaduje moji pozornost?**

## Gramatika

-   Context
-   Narrative
-   Insight
-   Action

## Projection

### Operations

-   Denní briefing
-   Timeline
-   Situace vyžadující pozornost
-   Detail případu
-   Předání případu
-   Dnešní posun
-   Slabá místa
-   Stav týmu

### Decision Intelligence

-   Rychlost rozhodování
-   Místa ztráty zákazníků
-   Co ovlivňuje rozhodnutí zákazníků

### Experience Quality

-   Připravenost Experience
-   Doporučená vylepšení

## Runtime vstupy

Decision Journey, Runtime Events, Team State, Experience Validation, AI
Recommendations.

## Runtime výstupy

Priority, doporučené akce, otevření případu, předání obchodníkovi.

## Architektonická pravidla

-   Runtime vytváří význam.
-   Projection skládá pohled.
-   Terminal pouze prezentuje.
