# Sales Terminal Specification v0.1

## Účel

Sales Terminal vede obchodníka k nejlepšímu dalšímu kroku během Decision
Journey klienta.

## Hlavní otázka

**Komu mám právě teď pomoci udělat další krok v rozhodování?**

## Gramatika

-   Context
-   Narrative
-   Insight
-   Action

## Projection

### Sales Operations

-   Sales Dashboard
-   Aktivní případy
-   Nové leady
-   Business Journey

### Decision Guidance

-   Decision Journey klienta
-   Poslední aktivita
-   AI doporučení
-   Next Best Action

## Runtime vstupy

Decision Journey, Priority změny, Runtime Events, Lead State.

## Runtime výstupy

Kontakt, schůzka, předání, poznámka.

## Architektonická pravidla

-   Sales Terminal není CRM.
-   Runtime vytváří doporučení.
-   Terminal pouze prezentuje.
