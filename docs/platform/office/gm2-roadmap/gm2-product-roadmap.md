# GM-2 Product Roadmap

**Version:** 1.0 · **CAP:** PT-20  
**Based on:** [Pilot Execution Report](../pilot-execution/pilot-execution-report.md) · [Operational Findings](../pilot-execution/operational-findings.md) · [Pilot Review](../pilot-execution/pilot-review.md)

## North star

Make multi-partner commercial pilots **durable, automated, and operable from documentation alone** — without re-architecting Embed Runtime or inventing CRM/AI scope.

## Timeline (logical, not calendar-locked)

```text
GM-2 Wave A — Reliability
  CAP-GM2-01 Persistence Foundation
  CAP-GM2-02 Commercial Automation Unification

GM-2 Wave B — Operations
  CAP-GM2-03 Production Mail & Payment Operations

GM-2 Wave C — Commercial clarity
  CAP-GM2-04 Document & Operator Clarity
  CAP-GM2-05 Builder Handoff & Pilot Polish
```

Wave A is a hard prerequisite for scaling beyond the founding partner.  
Wave B can start documentation/SOP tracks in parallel with Wave A engineering.  
Wave C assumes A landed (or explicitly waived).

## Non-goals (remain deferred)

- Full CRM
- AI commercial advisor
- Experimental UI redesign
- Bank pairing **product** (spike only inside CAP-GM2-03 unless re-scoped)
