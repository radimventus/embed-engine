# SP-07 --- Builder MVP

**Status:** Draft → SSOT po schválení

# Purpose

Builder je vstupní bod pro správu Projectů.

# Supported Operations

-   New Project
-   Open Project
-   Archive Project
-   Delete Project
-   Build Package
-   Publish Package

# Build & Publish

Builder: 1. otevře Project, 2. vytvoří Package, 3. publikuje Package.

Project se nikdy přímo nepublikuje.

# Success Criteria

Platforma umožňuje: - spravovat více Projectů, - vytvořit Package, -
publikovat Package.

> Builder spravuje Projecty. Publish pracuje nad Package.
