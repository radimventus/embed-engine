# ONS-SS-02 – Sales Dashboard

## Účel
Dashboard je výchozí obrazovka Sales Studia. Poskytuje obchodníkovi okamžitý přehled o stavu obchodních aktivit a doporučuje další krok.

## Primární otázka
**Co se dnes děje v mém obchodě?**

## Rozložení

1. Souhrn KPI
- Aktivní příležitosti
- Nové firmy
- Naplánované schůzky
- Čekající nabídky

2. Business Journey
Vizualizace počtu firem v jednotlivých fázích:
Kontakt → Prezentace → Pilot → Implementace → Aktivní klient

3. AI doporučení
Jedna prioritní akce pro dnešní den.

4. Poslední aktivita
Chronologický přehled posledních změn.

## UX pravidla
- Apple Easy
- One Screen → One Question
- Bez filtrů v MVP
- Bez dashboard builderu
- Maximálně 6 hlavních karet

## Akceptační kritéria
- Dashboard je pochopitelný do 5 sekund.
- Obchodník ihned ví, co má dnes udělat.
