# SP-02 --- Operations Timeline (ONS)

## Cíl

Implementovat Timeline jako lidsky čitelnou chronologii událostí.

## Hlavní scénář

1.  Otevření Timeline.
2.  Načtení interpretovaných událostí.
3.  Zobrazení skupin událostí.
4.  Pochopení vývoje případu.
5.  Návrat do Detailu případu.
