# CONIS DESIGN MANUAL v1.0

*Odvozeno ze SSOT `@embed-engine/design-tokens`*

## 1. Charakter značky

Conis působí:

-   klidně
-   sebevědomě
-   kultivovaně
-   nadčasově
-   profesionálně

Nikdy nepůsobí:

-   agresivně
-   technokraticky
-   startupově
-   futuristicky
-   přeplácaně

------------------------------------------------------------------------

## 2. Vizuální filozofie

Conis neprodává software.

Conis vytváří důvěru.

Proto musí každý vizuál působit jako:

-   kvalitní publikace,
-   architektonický katalog,
-   whitepaper.

Nikoli jako reklamní leták.

------------------------------------------------------------------------

## 3. Barevná identita (PR-022B)

Barva není dekorace. Barva vyjadřuje význam. Jedna barva = jedna role.

Builder, Manager, Sales i Platform jsou jeden produkt — barvy neodlišují Studia.

### Základní paleta

| Role | HEX |
| --- | --- |
| Navy | `#001930` |
| Gold Intense | `#B8922D` |
| Gold | `#C8A165` |
| White | `#FFFFFF` |
| Light Gray | `#E3E3E3` |
| Muted | `#64748B` |
| Cream Light | `#F7F6F4` |
| Cream Mid | `#E8E5E0` |
| Cream Dark | `#D9D4CC` |
| Green Intense | `#137A43` |
| Green Light | `#EAF5EE` |
| Red Intense | `#A93226` |
| Red Light | `#F8EBE9` |

Warning: zatím ponecháno pro další iteraci.

### Navy — jediná pracovní barva

Primary button / CTA, header, aktivní položky, odkazy, Anchor Rail, hlavní ikony, hlavní text.

### Gold — pouze Premium

Logo, premium badge, certifikace, střídmé zvýraznění. Nikdy primary button, canvas, formuláře, menu, běžné karty. Gold nesmí převážit nad Navy.

### Green — Success / PASS / Ready / Published

Green Intense: text, ikony, badge. Green Light: notice, background, success panel.

### Red — Error / FAIL / blokace / destructive

Red Intense: text, badge, destructive button. Red Light: error background / panel.

### Cream — materiál (ne status)

Canvas, pozadí, dialogy, formuláře, neutrální plochy, hover neutrálních prvků.

### Tlačítka

- Primary: Navy (hover tmavší Navy)
- Secondary: White (hover White + Navy border)
- Danger: Red
- Success: Green
- Nikdy Gold

### Focus

Jednotný decentní Navy/Gold focus ring. Žádný systémový světle modrý ring.

### Disabled

Cream Dark + Muted text. Bez hover.

### Zakázáno

Béžové/oranžové plochy, Gold tint panely, světle modré pracovní plochy, historické Builder blues, neodsouhlasené odstíny.

------------------------------------------------------------------------

## 4. Typografie

-   Font: Inter
-   Nadpisy: velké, vzdušné, 400--500
-   Text: 1rem
-   Line-height: 1.5
-   Zvýrazňovat pouze jednotlivá slova nebo krátké fráze.

------------------------------------------------------------------------

## 5. Práce s prostorem

Conis používá hodně bílého prostoru.

Prázdný prostor je součást designu.

------------------------------------------------------------------------

## 6. Kompozice

-   Jedna stránka = jedna myšlenka.
-   Jedna dominantní osa.
-   Minimum rušivých prvků.

------------------------------------------------------------------------

## 7. Fotografie

Preferovat:

-   architekturu
-   světlo
-   detail
-   materiál
-   prostor
-   přirozené situace

Nepoužívat:

-   stock obchodní fotografie
-   AI futurismus
-   datová centra
-   technologická klišé

------------------------------------------------------------------------

## 8. Ikony

-   outline
-   jednotná tloušťka
-   bez barevných ilustrací

------------------------------------------------------------------------

## 9. Diagramy

Maximální jednoduchost.

    Souvislosti
    ↓
    Porozumění
    ↓
    Důvěra
    ↓
    Rozhodnutí

------------------------------------------------------------------------

## 10. Karty

-   Background: White
-   Border: Light Gray
-   Radius: LG
-   Shadow: SM nebo žádný

------------------------------------------------------------------------

## 11. Tlačítka

Secondary: - White - Navy border - Gold hover
