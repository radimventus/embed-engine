# CONIS DESIGN MANUAL v1.0

*Odvozeno ze SSOT `@embed-engine/design-tokens`*

## 1. Charakter značky

Conis působí:

-   klidně
-   sebevědomě
-   kultivovaně
-   nadčasově
-   profesionálně

Nikdy nepůsobí:

-   agresivně
-   technokraticky
-   startupově
-   futuristicky
-   přeplácaně

------------------------------------------------------------------------

## 2. Vizuální filozofie

Conis neprodává software.

Conis vytváří důvěru.

Proto musí každý vizuál působit jako:

-   kvalitní publikace,
-   architektonický katalog,
-   whitepaper.

Nikoli jako reklamní leták.

------------------------------------------------------------------------

## 3. Barevná identita (PR-022C)

Barva není dekorace. Barva vyjadřuje význam. Jedna barva = jedna role.

**Navy = identita. Blue = interakce. Green = success.** Tyto role se nikdy nesmí zaměňovat.

Builder, Manager, Sales i Platform jsou jeden produkt — barvy neodlišují Studia.

### Základní paleta

| Role | HEX |
| --- | --- |
| Navy | `#001930` |
| Interaction Blue | `#18428F` |
| Gold Intense | `#B8922D` |
| Gold | `#C8A165` |
| White | `#FFFFFF` |
| Light Gray | `#E3E3E3` |
| Muted | `#64748B` |
| Cream Light | `#F7F6F4` |
| Cream Mid | `#E8E5E0` |
| Cream Dark | `#D9D4CC` |
| Green Intense | `#137A43` |
| Green Light | `#EAF5EE` |
| Red Intense | `#A93226` |
| Red Light | `#F8EBE9` |

Warning: zatím ponecháno pro další iteraci.

### Navy — identita (ne Primary Button)

Fonty, header, horní lišta, navigace, rámečky, oddělovače, základní ikony.

### Interaction Blue `#18428F` — jediná aktivní pracovní barva

Primary Button, CTA, hover, odkazy, focus, aktivní text/border/ikona, aktivní badge.

Jedna modrá pro celou platformu. Ne Green.

### Aktivní stav

Podklad: **Cream Dark**. Modrá pouze zvýrazňuje (text, border, ikona) — ne modrá plocha.

### Gold — pouze Premium

Logo, premium badge, certifikace, střídmé zvýraznění.

### Green — Success / PASS / Ready / Published

Green Intense: text, ikony, badge. Green Light: notice, background, success panel.

Green ≠ Navy. Green nikdy nenahrazuje interakční blue.

### Red — Error / FAIL / blokace / destructive

Red Intense: text, badge, destructive button. Red Light: error background / panel.

### Cream — materiál (ne status)

Canvas, pozadí, dialogy, formuláře, neutrální plochy. Cream Mid = secondary hover. Cream Dark = aktivní podklad.

### Tlačítka

- Primary: Interaction Blue fill (hover/pressed tmavší stejné modré)
- Secondary: outline Interaction Blue (hover Interaction Blue fill)
- Danger: Red
- Success: Green
- Nikdy Gold, nikdy Navy fill

### Focus

Jednotný Interaction Blue focus ring. Žádný systémový světle modrý ring.

### Disabled

Cream Dark + Muted text. Bez hover.

### Zakázáno

Béžové/oranžové plochy, Gold tint panely, studio-specific odstíny, Navy jako Primary Button, Green jako interakce.

## 4. Typografie

-   Font: Inter
-   Nadpisy: velké, vzdušné, 400--500
-   Text: 1rem
-   Line-height: 1.5
-   Zvýrazňovat pouze jednotlivá slova nebo krátké fráze.

------------------------------------------------------------------------

## 5. Práce s prostorem

Conis používá hodně bílého prostoru.

Prázdný prostor je součást designu.

------------------------------------------------------------------------

## 6. Kompozice

-   Jedna stránka = jedna myšlenka.
-   Jedna dominantní osa.
-   Minimum rušivých prvků.

------------------------------------------------------------------------

## 7. Fotografie

Preferovat:

-   architekturu
-   světlo
-   detail
-   materiál
-   prostor
-   přirozené situace

Nepoužívat:

-   stock obchodní fotografie
-   AI futurismus
-   datová centra
-   technologická klišé

------------------------------------------------------------------------
